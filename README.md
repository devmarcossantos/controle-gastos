# Controle de Gastos

API REST para registro e consulta de despesas pessoais, desenvolvida em Java com Spring Boot

## Tecnologias
- Java 17
- Spring Boot
- Spring Web
- Spring Data JPA
- H2 Database
- Maven
- Git e GitHub

## Funcionalidades
- [x] Rota inicial de teste
- [ ] Cadastro de Despesas
- [ ] Listagem de Despesas
- [ ] Consulta de Despesas por Categoria
- [ ] Atulização e Exclusão de Despesas
- [ ] Total de Gastos por mês
